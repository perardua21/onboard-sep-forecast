# 라벨 정의

출처는 `docs/spec.md`. 여기서는 코드가 실제로 하는 일을 적는다.

## 사건

```
시작  ≥10 MeV 적분 양성자 ≥ 10 pfu 인 점이 연속 3점   (SPHINX, 설계 기준 [26])
종료  ≥10 MeV < 5 pfu 가 연속 3시간
병합  기본 없음. 종료 규칙이 사건 분리를 결정한다.
```

연속 3점은 **분이 아니라 점 수**다. 5분 자료에서 15분, 1분 자료에서 3분이다.
시작 시각은 3점 구간의 **첫 점**으로 잡는다. 마지막 점으로 잡으면 선행시간이
자료 간격만큼 부풀려진다.

## 라벨

`y_H[t] = 1` ⟺ `(t, t+H]` 안에 사건 시작이 있다. H 는 30분과 60분 두 개다.

- `t` 시점의 값은 입력, `t` 이후 값은 라벨. 이 경계를 넘는 코드는 없어야 한다.
- 양성자 **과거값**은 입력에 들어간다. 미래값은 들어가지 않는다.
- 사건 **진행 중** 구간은 학습·평가에서 제외한다. 이미 벌어진 일을 맞히는 것은
  예측이 아니라 관측이고, 포함하면 탐지율이 올라간다.

## 경보

```
확률 ≥ 임계값 이 2회 연속 추론
```

임계값은 **검증집합에서만** 고르고 잠금 시험집합에서 재조정하지 않는다. 초기 탐색값은 0.7 이다.

기내 추론은 10초 주기이므로 2회 연속은 20초다. 지상 재현은 5분 격자 자료로
하므로 같은 2점이 10분이 된다. 이 차이 때문에 지상 재현의 선행시간은
기내보다 한 격자만큼 짧게 나온다. 표에 그대로 적고 보정하지 않는다.

## 선행시간 두 가지

| 이름 | 정의 | 어디서 계산하나 |
|---|---|---|
| 기내 선행시간 | 사건 시작 − 최초 경보 묶음 시작 | `evaluate.event_metrics` |
| 수신 선행시간 | 사건 시작 − 사용자 단말 최초 수신 | `delivery.receipt_lead` |

수신 시각은 남극 직접 가시(117.8분 중 12.43분)로 결정된다. 궤도 위상은
사건과 무관하므로 균등분포로 두고 몬테카를로로 분포를 낸다.
수신 선행시간이 0 이하인 경우는 **미수신**으로 따로 센다.
