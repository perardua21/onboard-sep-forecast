# 자료 사전

실제 파일을 열어 확인한 변수명이다 (2026-10-23 확인).
추측해서 적은 것은 없다. 확인하지 못한 항목은 그렇다고 적었다.

## 1. 세대 구분

| 기간 | X선 | 양성자 | 전자 |
|---|---|---|---|
| 2010 ~ 2019 | GOES-15 재처리 netCDF | GOES-15 EPEAD CSV | GOES-15 EPEAD CSV |
| 2020 ~ 2026 | GOES-16/18 netCDF | GOES-16/18 SGPS netCDF | GOES-16/18 MPS-HI netCDF |

**확인된 사실: GOES-16 SGPS(양성자) 자료는 2020년부터만 있다.**
2017년 폴더가 존재하지 않는다. 그래서 학습 구간(2010~2019)의 양성자는
전부 구세대 EPEAD 를 쓰게 된다.

이것이 뜻하는 바는 분명하다. **학습은 EPEAD, 잠금 시험은 SGPS 로 하게 된다.**
기기가 다르므로 성능 차이가 모델 때문인지 보정 차이 때문인지 섞인다.
설계 기준 한계에 반드시 적고, 검증 구간(2020~2022)이 두 기기에 걸치도록 해서
그 영향을 따로 본다.

## 2. X선 2채널

파일: `sci_xrsf-l2-avg1m_g{NN}_d{YYYYMMDD}_*.nc`

| 공통 이름 | 원본 변수 | 단위 | 대역 |
|---|---|---|---|
| `xrs_long` | `xrsb_flux` | W/m² | 1–8 Å |
| `xrs_short` | `xrsa_flux` | W/m² | 0.5–4 Å |

품질: `xrsb_flag` / `xrsa_flag` 가 0 이 아닌 표본은 결측으로 둔다.
`*_flux_observed` 는 전자 오염 보정 **전** 값이라 쓰지 않는다.
구세대 재처리판도 변수명이 같아 파서 하나로 전 기간이 된다.

M1급 = `xrs_long` ≥ 1×10⁻⁵ W/m².

## 3. 양성자 8채널

### 2010 ~ 2019 - GOES-15 EPEAD CSV

파일: `g15_epead_cpflux_5m_{YYYYMMDD}_{YYYYMMDD}.csv` (월 단위)

| 공통 이름 | 원본 열 | 비고 |
|---|---|---|
| `p_gt1` | `ZPGT1E`, `ZPGT1W` | |
| `p_gt5` | `ZPGT5E`, `ZPGT5W` | |
| **`p_gt10`** | **`ZPGT10E`, `ZPGT10W`** | **라벨 채널. 10 pfu = NOAA S1** |
| `p_gt30` | `ZPGT30E`, `ZPGT30W` | |
| `p_gt50` | `ZPGT50E`, `ZPGT50W` | |
| `p_gt60` | `ZPGT60E`, `ZPGT60W` | |
| `p_gt100` | `ZPGT100E`, `ZPGT100W` | |
| `p_gt500` | **없음** | EPEAD 는 >100 MeV 까지다 |

**E/W 처리** - 동쪽·서쪽 검출기 중 **최댓값**을 쓴다.
`<채널>_QUAL_FLAG` 가 0 이 아닌 표본은 먼저 버린다.

최댓값을 고른 이유: SEP 는 방향성이 있어 한쪽 검출기가 가려질 수 있고,
최댓값이 놓침을 줄이는 쪽이다. **이건 선택이지 정답이 아니다.**
평균을 썼을 때와 비교한 민감도를 실험 기록에 남겨야 한다.

`p_gt500` 은 구세대 구간에서 **결측**이다. HEPAD 의 `P8~P11_FLUX`
(약 330~700 MeV 미분 채널)를 참고값으로 같이 받지만, 이것으로
>500 MeV **적분** 플럭스를 만들지 않는다. 없는 값을 만들지 않는다.

### 2020 ~ 2026 - GOES-16/18 SGPS netCDF

파일: `sci_sgps-l2-avg5m_g{NN}_d{YYYYMMDD}_*.nc` (2021-10-28 파일로 확인)

**이 제품에는 ≥1·5·10·30·50·60·100 MeV 적분 플럭스가 없다.** 들어 있는 것은

| 변수 | 모양 | 뜻 |
|---|---|---|
| `AvgDiffProtonFlux` | (record, sensor_units 2, diff_channels 13) | 미분 플럭스, protons/(cm² sr keV s) |
| `DiffProtonEffectiveEnergy` | (sensor_units, diff_channels) | 채널 유효 에너지, keV |
| `DiffProtonLowerEnergy` / `UpperEnergy` | 같음 | 채널 경계, keV |
| `AvgIntProtonFlux` | (record, sensor_units) | **>500 MeV 적분 하나** (P11) |
| `L2_SciData_TimeStamp` | (record,) | 시각. 변수 이름이 `time` 이 아니다 |

그래서 ≥E 적분은 미분 채널로 만든다 (`ingest.integrate_spectrum`).

1. 채널 유효 에너지 사이를 로그-로그 직선(국소 멱법칙)으로 잇는다
2. 채널 범위 밖은 양 끝 기울기로 연장한다
3. E 부터 500 MeV 까지 적분하고 >500 MeV 채널을 더한다
4. 센서 두 개 중 큰 값을 쓴다 (EPEAD 동·서와 같은 취지)

멱지수 2·3·4 의 해석해와 비교해 모든 임계값에서 오차 0.1% 이내다.
**≥10 MeV 가 라벨 채널이므로 실제 사건으로도 확인해야 한다.**
`python scripts/check_probe.py` 가 2021-10-28 사건(S1)의 값을 보여준다.

이 계산은 NOAA 운용 적분값과 같은 알고리즘이 아니다. 같은 사건에서 SWPC 가
발표한 값과 비교한 차이를 실험 기록에 남긴다.

| 공통 이름 | 원본 |
|---|---|
| `p_gt1` ~ `p_gt100` | 미분 채널 적분 + P11 |
| `p_gt500` | `AvgIntProtonFlux` (센서 두 개 중 큰 값) |

### 같은 시각을 두 위성이 다 재고 있으면

연도별 정책 위성(2019년까지 GOES-15, 2020~2022 GOES-16, 2023~ GOES-18) 파일을
먼저 읽는다. 병합은 시각별 첫 유효값을 쓰므로 정책 위성 값이 남는다.

## 4. 전자 5채널

### 정지궤도 GOES 전자는 태양 선행 신호가 아니다

2017-09-10 같은 시각 GOES-15 EPEAD 와 GOES-16 MPS-HI 의 >2 MeV 전자를 비교하면
비 중앙값 0.83(10~90% 0.45~1.04), **로그 상관 −0.66** 이었다. 같은 물리량을 같은
시각에 쟀는데 반대로 움직인다. 정지궤도 >2 MeV 전자는 대부분 지구 방사선대
전자라 위성 위치에 따라 다르게 움직이고, EPEAD 전자 채널은 SEP 양성자에
오염된다고 알려져 있다. 어느 쪽이든 GOES 전자로는 "양성자보다 먼저 오는 태양
전자"를 잴 수 없다.

그래서 전자 선행 신호는 **ACE/EPAM** 으로 잰다. ACE 는 L1(태양풍 속)에 있어
방사선대와 무관하고, 1997년부터 지금까지 같은 기기라 학습·시험 구간이 이어진다.

### ACE/EPAM — `e_dif_lo`, `e_dif_hi`

CDAWeb HAPI 로 월 단위 CSV 를 받는다 (`AC_H1_EPM`, 5분 level 2).
`include=header` 로 받아 머리말의 변수 이름과 결측값을 그대로 쓴다.

| 공통 이름 | 원본 | 에너지 |
|---|---|---|
| `e_dif_lo` | `DE3` | 0.103–0.175 MeV |
| `e_dif_hi` | `DE4` | **0.175–0.315 MeV** (Núñez 2018, REleASE 가 쓰는 대역) |

전자 게이트는 `e_dif_hi` 를 먼저 쓴다 (`baselines.pick_electron_channel`).

### GOES 전자 — `e_gt0p8`, `e_gt2`, `e_gt4`

| 공통 이름 | 2010~2019 GOES-15 EPEAD | 2020~ GOES-16/18 MPS-HI |
|---|---|---|
| `e_gt0p8` | `E1E/E1W_COR_FLUX` (>0.8 MeV) | 없음 |
| `e_gt2` | `E2E/E2W_COR_FLUX` (>2 MeV) | `AvgIntElectronFlux` (E11 >2 MeV) |
| `e_gt4` | `E3E/E3W_COR_FLUX` (>4 MeV) | 없음 |

`_COR_FLUX`(보정본)를 쓰고, 동·서(또는 망원경 5개) 중 큰 값을 쓴다.
MPS-HI 의 미분 채널은 `e_mpsh_lo`, `e_mpsh_hi` 로 따로 두고 모델 입력에 넣지 않는다.

세대 공통인 `e_gt2` 만 정합 단계를 통과하지만, 위 이유로 선행 신호로서의 가치는
낮다. 제거 실험에서 `e_gt2` 를 뺀 경우와 비교한다.

## 5. 선량률 2채널

`dose_main`, `dose_backup` 은 달 궤도·표면 선량계 값이다.
**지구 근처 자료로는 채울 수 없다.**

코드는 0 으로 채우고 `dose_main_ok = 0`, `dose_backup_ok = 0` 으로 표시한다.
없는 값을 있는 것처럼 채우지 않는다. 제거 실험 표의 `no_dose (15채널)` 행이
지구 자료로 실제 돌릴 수 있는 설정이고, `fused17` 은 달 자료가 생긴 뒤의 설정이다.

달 환경 검증용 자료: LRO CRaTER (NASA PDS).

## 6. 품질 처리 규칙

- `*_QUAL_FLAG` 또는 `*_flag` 가 0 이 아니면 **결측**으로 둔다
- 음수, −1e30 이하는 결측
- **결측을 0 으로 채우지 않는다.** 플럭스 0 은 실제 관측일 수 있다
- 공통 시간축은 5분. 원본보다 높은 해상도를 만들지 않는다
- 시각은 모두 UTC

## 7. 검증 기록

2017년 9월 한 달치로 파서를 확인했다.

| 확인 항목 | 결과 |
|---|---|
| `p_gt10` 최대 | 1,333 pfu (9월 10일, GLE 72) |
| 사건 탐지 | 2건 - 2017-09-05, 2017-09-10 |
| 사건 지속 | 98.6 h, 102.7 h |
| 전자 `e_gt2` 최대 | 110,290 |

9월 10일 상승 과정: 12:00 에 0.86 pfu → 15:00 에 695 pfu → 최대 1,333 pfu.
NOAA 의 실제 사건 목록과 일치한다.

**남은 대조 작업**: GSEP 카탈로그를 받아 우리 `detect_events()` 결과와 맞춰본다.
9월 5~9일을 한 사건으로 묶은 것은 우리 종료 규칙(5 pfu 미만 3시간) 때문이며,
SWPC 목록은 더 잘게 나눌 수 있다. 어느 쪽이 맞다기보다 **정의가 다른 것**이므로,
어떤 정의를 썼는지 밝히고 GSEP 과의 차이를 수치로 보고한다.
